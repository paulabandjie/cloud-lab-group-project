SPEKTRONHOME HOSTEL PLAN
================================================================================

OVERVIEW
--------
SpektronHome is a student hostel website designed to provide information about
the hostel, showcase facilities and rooms, and allow students to make inquiries.

WEBSITE PAGES
-------------

1. Home Page (index.html)
   - Hero section
   - Hostel statistics
   - Features and amenities
   - Testimonials
   - Call-to-action section

2. About Page (about.html)
   - Mission and vision
   - Core values
   - Management/team profiles

3. Rooms Page (rooms.html)
   - Room listings
   - Private rooms
   - Shared rooms
   - Premium rooms
   - Room filtering options

4. Gallery Page (gallery.html)
   - Hostel photos
   - Room photos
   - Facility photos
   - Image preview/lightbox

5. Contact Page (contact.html)
   - Contact information
   - Inquiry form
   - Location/map section

6. Login Page (login.html)
   - Student login interface
   - Account access portal

ROOM CATEGORIES
